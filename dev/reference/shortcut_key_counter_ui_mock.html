統計データをすべて削除しますか？

詳細イベントと日次集計が削除されます。この操作は元に戻せません。設定と除外アプリ設定は保持されます。

管理者権限モードを有効にしますか？

管理者権限で動作するアプリ上のショートカット取得のため、入力取得専用プロセス ShortcutKeyCapture.exe をUAC昇格して起動します。UIとDB処理は通常権限のままです。
