## 運用ルール

- 状態: `TODO` / `IN_PROGRESS` / `REVIEW` / `DONE` / `BLOCKED`
- 優先度: P0=前提・停止条件、P1=v0.2.0必須、P2=繰越可
- 工数: S=半日以内、M=1〜2日、L=3〜5日、Spike=上限を決めた実証
- 件数・行数ではなく、記載した利用者シナリオと安全条件で完了を判定する。
