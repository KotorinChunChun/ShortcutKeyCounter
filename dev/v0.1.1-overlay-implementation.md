# ShortcutKeyCounter v0.1.1 Overlay実装報告

作成日: 2026-08-16

## 実装概要

承認済み `ShortcutKeyCounter_v0.1.1_Overlay_Design.md` に基づき、ショートカット入力オーバーレイを実装した。

## 実装した機能

- Rust + Win32 Native Layered Window
- `WS_EX_LAYERED / WS_EX_TRANSPARENT / WS_EX_TOOLWINDOW / WS_EX_NOACTIVATE / WS_EX_TOPMOST`
- `WM_NCHITTEST -> HTTRANSPARENT` によるclick-through補強
- Foreground Windowがあるモニターの `rcWork` 中央下へ配置
- Per-monitor DPIスケーリング
- Overlay Windowは1個だけ生成して再利用。Itemが0件なら非表示
- Captureからbounded channelへnonblocking `try_send`
- 最大3件のStack
- 160ms Slide/Fade In
- 0.16～1.00秒の完全表示
- 1.00～1.40秒の400ms Fade Out
- DB用1秒DuplicateGuardより前にOverlay通知
- Local/Elevated別sourceの同一物理入力を50msでOverlay専用dedup
- SVG (`key.svg`, `modifier.svg`, `mouse.svg`) の読み込み・ラスタライズ
- SVG templateとshortcut描画結果のcache
- `overlay_key_labels.json` による表示文字列mapping
- `overlay-theme.json` による位置・サイズ・animation設定
- SQLite `settings.overlay_enabled` 永続化
- Settings UIからON/OFF、JSON/SVGを開く、asset再読み込み
- JSON破損時はdefault fallback。ユーザーファイルは削除・上書きしない
- Overlay初期化/描画失敗はOverlayだけ無効化し、Capture/DBを継続

## Capture処理順

```text
is_recordable
→ normalize
→ key mapping
→ foreground executable validation
→ excluded app
→ Overlay try_show
→ DB 1-second DuplicateGuard
→ SQLite record
```

この順序により、ユーザーが0.3秒間隔で実際に `Ctrl+C` を2回押した場合、DBは既存仕様どおり1件でもOverlayは2回表示する。

## 設定ファイル

```text
%LOCALAPPDATA%\ShortcutKeyCounter\overlay_key_labels.json
%LOCALAPPDATA%\ShortcutKeyCounter\overlay-theme.json
%LOCALAPPDATA%\ShortcutKeyCounter\overlay\default\key.svg
%LOCALAPPDATA%\ShortcutKeyCounter\overlay\default\modifier.svg
%LOCALAPPDATA%\ShortcutKeyCounter\overlay\default\mouse.svg
```

## デフォルトTiming

| Phase | Time |
|---|---:|
| Slide/Fade In | 160ms |
| Fully visible end | 1,000ms |
| Fade Out | 400ms |
| Complete removal | 1,400ms |

## 静的回帰Gate

`scripts/build-release.ps1` に以下を追加した。

- 160/840/400msのdefault timing
- max 3 items
- 50ms source dedup
- Elevated eventが `try_send_elevated` を使用
- `WS_EX_NOACTIVATE` / `WM_NCHITTEST` / `HTTRANSPARENT`
- Overlay通知がDB DuplicateGuardより前
- Overlay subsystemへのWebView依存混入禁止

## Windows実機で必要な最終確認

- 実際の表示位置とanimation
- 1.4秒TTL
- 連続3件stack / 4件目の動作
- マルチモニター / 異DPI
- click-through / focus非奪取
- Elevated併用時の二重表示なし
- 同じshortcutを1秒以内に2回押した場合にOverlayは2回表示
- Overlay OFF
- JSON/SVG編集とreload
- idle CPU / memory / rapid input
