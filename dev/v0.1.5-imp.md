# ShortcutKeyCounter v0.1.5 実装計画・報告

作成日: 2026-08-29  
対象要求: `V15-REPO-01`、`V15-DOC-01` および 2026-08-29追加UI要求

## 1. 目的

公開リポジトリを推奨フォルダ構成へ整理し、配布成果物とソースコードを分離する。あわせて、画像を後から差し込める利用者向け手順書を整備する。

追加UI要求では、アクティブウィンドウ回避の既定位置を安全な下端2位置へ絞り、キーマッピング一括変更の操作対象を拡張する。また、表見出しとコンボボックスのテーマ表示を修正する。

## 1.1 事前確認

- オーバーレイ既定位置は `apps/shortcut-key-counter/src/overlay/config.rs` の `default_allowed_positions` で9位置を返していたため、ここを変更する。
- キーマッピング一括変更は `apps/shortcut-key-counter/ui/src/main.ts` の `bulkMappingChange` と `index.html` の3ボタンで実装されている。`continue_display` と `record_and_display_break` は既存のKeyActionとして利用可能である。
- コンボボックスの共通CSSは `ui/styles/main.css` にあるが、`option` のテーマ別文字色・背景色指定がない。
