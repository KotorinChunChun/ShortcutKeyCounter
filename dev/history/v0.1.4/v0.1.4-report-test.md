## 3. 実施できなかった項目

この環境では以下のコマンドは `cargo: command not found` のため実行不可だった。

```text
cargo check --workspace --all-targets --all-features
cargo clippy --workspace --all-targets --all-features -- -D warnings
cargo test --workspace --all-features
```

同様にWindows専用の以下は未実施。

- Win32 Low-Level Hook
- Native Layered Overlay
- click-through / no-activate
- UI Automation password判定
- Integrity Level / UAC / Elevated helper
- Tray
- multi-monitor / DPI
- horizontal wheel hardware
- sleep / hibernate / lock / resume
- Tauri installer/package

## 4. Windows側で必須の最終確認

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\build-release.ps1
```
