# ShortcutKeyCounter v0.1.4（暫定版）

Windowsのバックグラウンドに常駐し、入力されたショートカットキーをキー別、アプリ別、時間軸でローカル集計するツールです。「どのアプリで、どのショートカットが実際に使われているか」を、リアルタイムログ、ランキング、グラフ、ヒートマップで確認できます。

Keyvizのように、入力したショートカットを画面上へポップアップ表示するショートカットキービジュアライズ機能も搭載しています。

ZIPを展開し、`ShortcutKeyCounter.exe` と `ShortcutKeyCapture.exe` を同じフォルダーに置いたまま、`ShortcutKeyCounter.exe` を実行してください。

実行ファイルはコード署名されていないため、Windowsの警告が表示される場合があります。公式GitHubから取得したファイルであることと、次のSHA-256が一致することを確認してください。

```text
615012808DA2DDB60D7EDA50C037246980205100C723FD446EC7D9FADA824226
```

## 確認できる内容

- 記録対象になったショートカットのリアルタイムログ
- 今日・7日・30日・全期間のキー別ランキング
- アプリ別ランキングと、そのアプリで使用したキーの内訳
- キー別・アプリ別の使用率グラフ
- キーとアプリの組み合わせを示すヒートマップ形式のマトリクス
- 日次集計・詳細イベントのCSV出力
- SQLite DBバックアップ

CSVはExcel等へ読み込み、独自の集計やグラフ作成に利用できます。内容を確認・匿名化したうえで、他の人へ共有することもできます。

## ショートカットキービジュアライズ

作業配信や画面共有で使いやすいよう、次の項目を細かく設定できます。

- 画面に表示するキーと修飾キーパターンの全組み合わせ
- 日本語キーボード固有キーを含む表示名
- デスクトップ／アクティブウィンドウ、モニター、9か所の表示位置
- 背景色、透明度、表示時間、最大行数、IN/OUTアニメーション
- 同じキーを3回以上連続入力した場合の `×N` 圧縮表示
- 連打カウンターの色、形状、角度、フォントサイズ

連打を `×N` にまとめて画面を埋めにくくする仕組みは、特にこだわった機能です。より楽しいアニメーションやデザインのアイデアは[GitHub Issues](https://github.com/KotorinChunChun/ShortcutKeyCounter/issues)へお寄せください。

## 安全対策

キー入力の監視にはセキュリティ上のリスクがあるため、次の対策を実装しています。

- パスワード・資格情報入力等を検知した場合は、安全側に表示・記録を停止する
- 修飾キーなしの単独入力はログへ永続記録しない
- Security Gateをオーバーレイ、リアルタイムログ、DB記録より前に適用する
- 除外アプリと高権限アプリを保護する
- 計測・集計・CSV機能はネットワーク通信を行わず、計測データを外部へ自動送信しない

ヘルプ画面からGitHubを開く操作を行った場合だけ、既定ブラウザーが外部サイトへアクセスします。

### 利用上の注意

あらゆるアプリや入力欄を完全に判定できることは保証できません。例えば、単独キーのオーバーレイ表示を有効にした状態で画面共有し、仕様で想定していない入力欄へパスワードを入力すると、その入力欄が安全に検出されず、入力内容が画面へ表示される可能性があります。

パスワードや機密情報を入力する前に、画面共有を停止するか、オーバーレイと計測を停止してください。ご自身の環境で保護動作を確認し、十分に注意してご利用ください。

## 統計データ共有のお願い

もしよければ、みんなで本当に有用なショートカットキーランキングを作るため、匿名化した集計データの共有にご協力ください。共有方法は[GitHub Issues](https://github.com/KotorinChunChun/ShortcutKeyCounter/issues)でご相談ください。

共有は完全に任意です。CSVにはショートカット名、アプリ名、利用時刻等が含まれる場合があります。共有前に内容を確認し、個人・勤務先・作業内容を推測できる情報を削除してください。SQLite DBや未確認の詳細イベントCSVを、そのまま公開しないでください。本ツールが統計データを自動送信することはありません。

## v0.1.4の主な変更

- DuplicateGuardを0.0～10.0秒、詳細イベント保持を1～365日で設定可能に変更
- キーマッピングへ分類フィルター、一括変更、物理キー検索を追加
- キー別・アプリ別ランキングを統合し、期間比較、平均、構成比、比較率へ対応
- キー別・アプリ別の使用率グラフを追加
- オーバーレイへ700msの連打判定と、3回目からの `×N` 圧縮表示を追加
- 連打カウンターの外観設定とプレビューを追加
- 本番DBと検証DBを分離し、検証DBだけへサンプルデータを生成
