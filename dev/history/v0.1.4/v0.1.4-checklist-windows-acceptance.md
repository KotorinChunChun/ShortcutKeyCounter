# ShortcutKeyCounter v0.1.4 Windows受入試験チェックリスト

作成日: 2026-08-18

## A. Build

- [ ] `cargo fmt --all -- --check`
- [ ] `cargo check --workspace --all-targets --all-features`
- [ ] `cargo clippy --workspace --all-targets --all-features -- -D warnings`
- [ ] `cargo test --workspace --all-features`
- [ ] `cargo build --release -p shortcut-key-counter -p shortcut-key-capture`
- [ ] TypeScript build
- [ ] Tauri package build

## B. Security Gate

- [ ] `A`等の修飾なしkeyboardを入力してもDB/Realtime Log/diagnosticへ残らない。
- [ ] MouseLeft/Right/Middle/X1/X2単独はOverlay表示できるがDB/Realtime Logへ残らない。
- [ ] WheelUp/Down/Left/Right単独はOverlayにも出ず、DB/Realtime Logへ残らない。
- [ ] Ctrl/Alt/Shift/Win単独はOverlay/DB/Realtime Logへ出ない。
- [ ] password/credential入力中はOverlay/DB/Realtime Log/statisticsが停止する。
- [ ] Security判定失敗時はFail Closedになる。
- [ ] 通常権限processから高Integrity foregroundの入力を処理しない。

## C. Settings

- [ ] 「表示先」comboを最後まで操作でき、選択直後に閉じない。
- [ ] 固定monitorへ切替直後にmonitor comboがenabledになる。
- [ ] 複数monitor時は対象選択前にvalidation errorで旧値へ戻らない。
- [ ] monitorが1台だけなら固定選択時に自動選択できる。
- [ ] 保存済みmonitorが切断されても別monitorを勝手に選択しない。
- [ ] Light themeの9位置選択は青背景・白文字。
- [ ] DuplicateGuardを0.0〜10.0秒で変更し、次イベントから反映する。
- [ ] DuplicateGuard=0でDB重複抑制が無効になる。
- [ ] retentionを1〜365日に変更し、次回retention処理で反映する。

## D. Key Mapping

- [ ] ページ全体ではなくmatrixだけが縦scrollする。
- [ ] 分類filterと一括変更がdesktop幅で横並び。
- [ ] 修飾列0件で一括変更を押してもbackendを呼ばず「列を選択してください」と表示する。
- [ ] 「キーを入力して検索」後の次の物理keyで該当行へscrollする。
- [ ] 検索に使った入力がOverlay/DB/Realtime Log/statisticsへ出ない。

## E. Ranking

- [ ] キー別/アプリ別がdesktop幅で左右2ペイン。
- [ ] 今日 / 7日 / 30日 / 全期間を切替できる。
- [ ] 今日の比較は前日の同時刻までであり、前日24h全体にならない。
- [ ] 対象アプリ変更でcount/average/ratio/comparison/rankが再計算される。
- [ ] Allの平均はデータ存在日数、アプリfilter時はfilter後のデータ存在日数を分母にする。
- [ ] 各headerのsortが「降順 → 昇順 → なし」で循環する。
- [ ] 有効sort列は1列だけ。
- [ ] アプリ利用時間は `2時間14分` / `43分` 形式。
- [ ] 上位4アプリcardが表示されない。

## F. Usage Graph

- [ ] キーごと/アプリごとを切替できる。
- [ ] 初期状態で1〜5位ON、6位以下OFF。
- [ ] 系列一覧clickでON/OFFできる。
- [ ] 今日=hour、7日=day、30日=day、全期間=monthのbucketになる。
- [ ] 色chip変更が即graph/legendへ反映する。
- [ ] 再起動後も内部identityごとの色が維持される。

## G. Overlay Repeat

- [ ] `A A A` → `A ×3`。
- [ ] 4回目以降は `×4`, `×5` とcountだけ増える。
- [ ] `Ctrl+C` 3回 → `Ctrl + C ×3`。
- [ ] MouseLeft 5回 → `MouseLeft ×5`。
- [ ] 700ms以内は同一run、700ms超過は新run。
- [ ] 別identityでrun終了。
- [ ] password等でSecurity Gateが閉じると既存Overlay sessionが消え、復帰後に同じrunへ継続しない。
- [ ] countだけbumpし、既存keycapのIN animationを再実行しない。
- [ ] Overlay `×N` とDB保存件数がDuplicateGuard設定により異なっても正常。
- [ ] Repeat counter設定とNative Overlay/画面内Previewの外観が一致する。

## H. Overlay retreat click

- [ ] Overlay bounds内MouseLeftで反対位置へ退避する。
- [ ] center → bottom-right。
- [ ] 背面applicationへ元clickが届く。
- [ ] focusをShortcutKeyCounterへ奪わない。
- [ ] Ctrl等を押しながらOverlayをclickしても`Ctrl+MouseLeft`としてDB/Realtime Log/Overlay/statisticsへ入らない。

## I. Sample Data

- [ ] Production DB選択中はsample generation APIが拒否される。
- [ ] Test DB選択中のみ生成できる。
- [ ] Production DBのapplication/recordable shortcut identityを母集団にする。
- [ ] 前日を最新日として60日へ分布し、当日分を生成しない。
- [ ] 約10,000eventを生成する。
- [ ] `shortcut_daily`とeventのaggregateが整合する。
- [ ] `application_usage_daily`が60日あり、1日合計24hを超えない。
- [ ] 前日分Realtime Logサンプルが200件表示される（10,000件生成時）。
- [ ] Realtime Logサンプルにunmodified単独入力/Modifier-onlyが含まれない。

## J. Regression

- [ ] multi-monitor + 100/125/150% DPI。
- [ ] horizontal wheel hardware。
- [ ] Elevated helper ON/OFF/UAC/cancel/helper kill。
- [ ] Sleep/Hibernate/Lock/Unlock/Resume。
- [ ] WebView close/recreate lifecycle。
- [ ] Tray 3-state visual。
- [ ] Dark/Light往復。
- [ ] rapid inputでhook遅延・queue saturation・memory増加がない。
