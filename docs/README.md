# 利用者向けドキュメント

ShortcutKeyCounterは、Windowsのバックグラウンドでショートカット利用をローカル集計し、リアルタイムログ、キー別・アプリ別ランキング、使用率グラフ、ヒートマップ、CSV出力、画面上のキー表示を提供します。
