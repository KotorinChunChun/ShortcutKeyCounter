## 撮影ルール

- ダッシュボード、ランキング、グラフ等は検証DBのサンプルデータで撮影する。
- ユーザー名を含むパス、実際の利用アプリ、ショートカット履歴、個人情報を写さない。
- パスワード、資格情報、APIキー、社内限定URLが写った画像は保存しない。
- やむを得ず機密情報が入る場合は、画像編集ソフトで完全にマスクしてからGitへ追加する。
- 画像追加後は、原寸表示とGitHub上の表示の両方で文字が読めることを確認する。
